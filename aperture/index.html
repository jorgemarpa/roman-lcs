    Aperture Photometry

    Aperture photometry methods and optimal aperture selection.

    aperture

    Collection of aperture utils lifted from Kepler-Apertures and adapted to work with PSFMachine.

    Some this functions inputs and operate on a Machine object but we move them out of mahine.py to keep the latter smowhow clean and short.

    compute_CROWDSAP 

    compute_CROWDSAP(
    psf_models, aperture_mask, idx=None, flux_weights=None
)

    Compute the ratio of target flux relative to flux from all sources within the photometric aperture (i.e. 1 - Crowdedness). Follows definition by Kinemuchi et al. 2012: CROWDSAP = sum_{p in aperture} F_target(p) / sum_{p in aperture} F_total(p)

    Parameters:

    Name Type Description Default
    psf_models csr_matrix or ndarray

    Matrix with the PSF models for all targets in the scene. It has shape [n_sources, n_pixels].

    		 required
    aperture_mask ndarray

    Array of boolean indicating the aperture for the target source. It has shape of [n_sources, n_pixels] or [n_pixels].

    		 required
    idx int

    Source index for which the metric is computed. Value has to be between 0 and psf_models first dimension size. If None, it returns the metric for all sources.

    		 None
    flux_weights ndarray

    Array of flux estimates for each source with shape [n_sources]. If provided, psf_models will be weighted by these fluxes before computing metrics.

    		 None

    Returns:

    Name Type Description
    CROWDSAP ndarray or float

    Crowdedness metric

    correct_aperture_flux 

    correct_aperture_flux(
    flux: ndarray,
    flux_err: ndarray,
    flfrcsap: ndarray,
    crowdsap: ndarray,
) -> Tuple[ndarray, ndarray]

    Correct aperture flux and flux error for contamination (crowding) and enclosed flux fraction.

    Formulas: flux_removed = flux - (1 - crowdsap) * np.nanmedian(flux) flux_corr = flux_removed / flfrcsap flux_err_corr = flux_err / flfrcsap

    Parameters:

    Name Type Description Default
    flux ndarray

    Raw aperture flux array.

    		 required
    flux_err ndarray

    Raw aperture flux uncertainty array.

    		 required
    flfrcsap ndarray

    Fraction of target flux enclosed in the aperture (completeness).

    		 required
    crowdsap ndarray

    Ratio of target flux to total flux in the aperture (crowding metric).

    		 required

    Returns:

    Name Type Description
    flux_corr ndarray

    Aperture flux corrected for crowding and flux completeness.
    flux_err_corr ndarray

    Corresponding corrected flux uncertainties.

    make_snr_optimal_aperture 

    make_snr_optimal_aperture(
    signal: ndarray,
    error: ndarray,
    sat_flux: float = 60000.0,
    plot: bool = False,
) -> ndarray

    Generate an optimal photometric aperture mask by maximizing the cumulative Signal-to-Noise Ratio (SNR).

    The optimal aperture is determined by finding the pixel count that maximizes the total SNR or where the SNR improvement flattens out, ensuring that heavily saturated pixels are always enclosed before the cutoff is applied.

    Parameters:

    Name Type Description Default
    signal ndarray

    Array representing the estimated target flux or PRF model per pixel in electrons/sec.

    		 required
    error ndarray

    Array of the corresponding flux errors (e.g., background and Poisson noise) per pixel.

    		 required
    sat_flux float

    Flux threshold above which pixels are considered saturated. Defaults to 6e4.

    		 60000.0
    plot bool

    If True, generates a diagnostic plot showing the cumulative SNR curve and the selected optimal pixel count cutoff. Defaults to False.

    		 False

    Returns:

    Name Type Description
    optimal_mask ndarray

    A boolean mask of the same shape as the input signal, where True indicates that a pixel is included in the optimal aperture.

    optimize_aperture 

    optimize_aperture(
    psf_model,
    target_complete=0.9,
    target_crowd=0.9,
    max_iter=100,
    percentile_bounds=[0, 100],
    quiet=False,
)

    Function to optimize the aperture mask for a given source.

    The optimization is done using scipy Brent's algorithm and it uses a custom loss function goodness_metric_obj_fun that uses a Leaky ReLU term to achive the target value for both metrics.

    Parameters:

    Name Type Description Default
    psf_model csr_matrix

    Sparse matrix with the PSF models for all targets in the scene. It has shape [n_sources, n_pixels].

    		 required
    target_complete float

    Value of the target completeness metric.

    		 0.9
    target_crowd float

    Value of the target crowdeness metric.

    		 0.9
    max_iter int

    Numer of maximum iterations to be performed by the optimizer.

    		 100
    percentile_bounds tuple

    Tuple of minimun and maximun values for allowed percentile values during the optimization. Default is the widest range of [0, 100].

    		 [0, 100]

    Returns:

    Name Type Description
    optimal_percentile ndarray

    An array with the percentile value to defines the "optimal" aperture for each source.
