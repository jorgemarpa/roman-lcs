    compute_p2p_scatter 

    compute_p2p_scatter(
    flux: ndarray,
    time: Optional[ndarray] = None,
    normalize: bool = False,
    ppm: bool = False,
) -> float

    Compute the point-to-point ($\sigma_{\text{P2P}}$) scatter of a light curve.

    The point-to-point scatter is calculated using: $$\sigma_{\text{P2P}} = \frac{1.4826}{\sqrt{2}} \text{MAD}(\Delta y)$$ where $\Delta y$ is the difference between consecutive points in the flux or magnitude time-series, and $\text{MAD}(\Delta y)$ is the median absolute deviation of $\Delta y$: $$\text{MAD}(\Delta y) = \text{median}(|\Delta y - \text{median}(\Delta y)|)$$

    Parameters:

    Name Type Description Default
    flux ndarray

    Flux or magnitude time-series array.

    		 required
    time ndarray

    Time values corresponding to the cadences. If provided, observations are sorted by time before computing consecutive differences.

    		 None
    normalize bool

    If True, normalize by the median flux (dimensionless relative scatter).

    		 False
    ppm bool

    If True, normalize by the median flux and express in parts-per-million (ppm). Overrides normalize.

    		 False

    Returns:

    Name Type Description
    p2p_scatter float

    Point-to-point scatter $\sigma_{\text{P2P}}$.

    sparse_lessthan 

    sparse_lessthan(
    arr: spmatrix, limit: Union[float, ArrayLike]
) -> spmatrix

    Compute less than operation on sparse array by evaluating only non-zero values and reconstructing the sparse array. This function return a sparse array, which is crutial to keep operating large matrices.

    Notes: when doing x < a for a sparse array x and a > 0 it effectively compares all zero and non-zero values. Then we get a dense boolean array with True where the condition is met but also True where the sparse array was zero. To avoid this we evaluate the condition only for non-zero values in the sparse array and later reconstruct the sparse array with the right shape and content. When x is a [N * M] matrix and a is [N] array, and we want to evaluate the condition per row, we need to iterate over rows to perform the evaluation and then reconstruct the masked sparse array.

    Parameters:

    Name Type Description Default
    arr sparse

    Sparse array to be masked, is a 2D matrix.

    		 required
    limit (float, array)

    Upper limit to evaluate less than. If float will do arr < limit. If array, shape has to match first dimension of arr to do `arr < limi[:, None]`` and evaluate the condition per row.

    		 required

    Returns:

    Name Type Description
    masked_arr csr_matrix

    Sparse array after less than evaluation.

    threshold_bin 

    threshold_bin(
    x: ArrayLike,
    y: ArrayLike,
    z: ArrayLike,
    z_err: Optional[ArrayLike] = None,
    abs_thresh: int = 10,
    bins: int = 15,
    statistic: Callable = nanmedian,
) -> Tuple[ndarray, ndarray, ndarray, ndarray, ndarray]

    Function to bin 2D data and compute array statistic based on density. This function inputs 2D coordinates, e.g. X and Y locations, and a number value Z for each point in the 2D space. It bins the 2D spatial data to then compute a statistic, e.g. median, on the Z value based on bin members. The statistic is computed only for bins with more than abs_thresh members. It preserves data when the number of bin memebers is lower than abs_thresh.

    Parameters:

    Name Type Description Default
    x ndarray

    Data array with spatial coordinate 1.

    		 required
    y ndarray

    Data array with spatial coordinate 2.

    		 required
    z ndarray

    Data array with the number values for each (X, Y) point.

    		 required
    z_err ndarray

    Array with errors values for z.

    		 None
    abs_thresh int

    Absolute threshold is the number of bib members to compute the statistic, otherwise data will be preserved.

    		 10
    bins int or list of ints

    Number of bins. If int, both axis will have same number of bins. If list, number of bins for first (x) and second (y) dimension.

    		 15
    statistic callable()

    The statistic as a callable function that will be use in each bin. Default is numpy.nanmedian.

    		 nanmedian

    Returns:

    Name Type Description
    bin_map ndarray

    2D histogram values
    new_x ndarray

    Binned X data.
    new_y ndarray

    Binned Y data.
    new_z ndarray

    Binned Z data.
    new_z_err ndarray

    BInned Z_err data if errors were provided. If no, inverse of the number of bin members are returned as weights.
