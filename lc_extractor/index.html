    from_file staticmethod 

    from_file(
    fname: Union[str, List[str], ndarray],
    cutout_size: int = 32,
    cutout_center: Union[
        Tuple[float, float], Tuple[int, int]
    ] = (0, 0),
    sources: Optional[DataFrame] = None,
    file_version: str = "1.0",
    **kwargs,
) -> LCExtractor

    Reads data from files and initiates a new object of LCExtractor class. Two options are available: 1. If providing pixel coordinates with cutout_origin, the data will be fixed tothe pixel grid, no dithering correctin will be applied and the star field will move across the image. 2. When providing cutout_center in RA, Dec coordinates, the data will be cetered in the target coordinate and account for dithering. The star field will be fixed, but the pixel grid will change.

    Parameters:

    Name Type Description Default
    fname str or list of strings

    File name or list of file names of the FFI files.

    		 required
    cutout_size int

    Size of the cutout in pixels, assumed to be squared.

    		 32
    cutout_center tuple of floats

    Center of the cutout in RA, Dec coordinates. If provided, the cutout will be centered on this position and the pixel grid will be adjusted to account for dithering.

    		 (0, 0)
    sources DataFrame

    Catalog with sources to be extracted by PSFMachine

    		 None
    **kwargs dictionary

    Keyword arguments that defines shape model in a Machine class object. See psfmachine.Machine for details.

    		 {}

    PRFFitFlag

    Bases: IntFlag

    Bitmask flags tracking PRF scene model fitting quality and convergence.

    Attributes:

    Name Type Description
    SUCCESS int(0)

    Fit succeeded and converged normally.
    NOT_CONVERGED int(1)

    Iterative centroid shift did not reach convergence threshold within max iterations.
    MAX_ITER_REACHED int(2)

    Iterative fitting stopped because maximum iterations was reached.
    LINALG_FAILED int(4)

    Linear solver failed (LinAlgError or singular design matrix).
    NON_FINITE_WEIGHTS int(8)

    Linear solve produced non-finite (NaN or Inf) weights or flux errors.
    INSUFFICIENT_UNMASKED_PIXELS int(16)

    Insufficient unmasked pixels in cutout to constrain model.
    DIVERGED_OFFSET int(32)

    Centroid offset step diverged or exceeded physical bound (> 1.5 pix).
    NEGATIVE_FLUX int(64)

    Fitted flux for one or more target stars is negative.
    HIGH_CHI2 int(128)

    Model reduced chi-squared is unusually high (> 10.0).
